# BSPWM Keybinds

`Super` is the Windows key.

## Apps

| Keybind | Action |
| --- | --- |
| `Super + Enter` | Open Alacritty |
| `Super + D` | App launcher |
| `Super + Shift + D` | Run command |
| `Super + Shift + Enter` | Window switcher |
| `Super + Shift + F` | Open Firefox |
| `Super + Shift + C` | Open VS Code |
| `Super + Shift + N` | Open Thunar |
| `Super + Shift + A` | Audio settings |
| `Super + Shift + B` | Bluetooth manager |
| `Super + Shift + X` | Power menu |

## Screenshots

| Keybind | Action |
| --- | --- |
| `Print` | Flameshot GUI |
| `Super + Print` | Full screenshot |
| `Super + Shift + Print` | Area screenshot |

## Audio And Brightness

| Keybind | Action |
| --- | --- |
| `Volume Up` | Increase volume |
| `Volume Down` | Decrease volume |
| `Mute` | Toggle mute |
| `Brightness Up` | Increase brightness |
| `Brightness Down` | Decrease brightness |

## Session

| Keybind | Action |
| --- | --- |
| `Ctrl + Shift + Q` | Quit BSPWM |
| `Ctrl + Shift + R` | Restart BSPWM |
| `Super + Escape` | Reload sxhkd config |
| `Super + Q` | Close window |
| `Super + Shift + Q` | Kill window |

## Layouts

| Keybind | Action |
| --- | --- |
| `Super + Space` | Toggle floating/tiled |
| `Super + T` | Set tiled |
| `Super + Shift + T` | Set pseudo-tiled |
| `Super + F` | Set fullscreen |

## Focus And Swap

| Keybind | Action |
| --- | --- |
| `Super + H/J/K/L` | Focus west/south/north/east |
| `Super + Shift + H/J/K/L` | Swap west/south/north/east |
| `Alt + Tab` | Focus next window |
| `Alt + Shift + Tab` | Focus previous window |
| `Super + Grave` | Focus last window |
| `Super + Tab` | Focus last desktop |

## Workspaces

| Keybind | Action |
| --- | --- |
| `Super + 1..5` | Switch to workspace 1..5 |
| `Super + Shift + 1..5` | Move window to workspace 1..5 |

## Resize

| Keybind | Action |
| --- | --- |
| `Super + Ctrl + H/J/K/L` | Resize left/bottom/top/right |
| `Super + Alt + H/J/K/L` | Resize opposite edge |
